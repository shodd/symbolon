Quiet

Quiet gets out of the way. It looks like a well-made system app on each platform, so trust comes from familiarity, not branding: grouped lists, hairline dividers, the platform font and one restrained pine accent (or the user's OS accent colour where the platform exposes one). It suits people who open a password manager ten times a day and want each visit to be short and uneventful.

Logo mark

A round token broken along a zig-zag cut. The solid half is what you know (your password); the outlined half is what you hold (your Secret Key). Only these two edges fit together. It reads as a simple coin at 16 px, and the monochrome version works as a menu-bar or tray icon.

Notes for Flutter and accessibility

  • Flutter: one ThemeData per mode plus a ThemeExtension for the extra roles (surface-2, line, accent-weak). Grouped lists are plain Columns of ListTiles inside a bordered DecoratedBox. The adaptive bits are platform-aware: back gesture, title-bar controls, switch styles and the large iOS title.
  • System accent: where the OS exposes an accent colour (macOS, Windows, Android 12+ dynamic colour), it replaces pine, but only after it passes the same 4.5 : 1 check. Otherwise the app falls back to pine.
  • Monograms, not favicons: item icons are drawn locally, so no network request reveals which sites a user has accounts on.
  • Contrast: every text pair above meets WCAG AA (4.5 : 1) and control borders meet 3 : 1, in both modes.
  • Targets: every interactive element is at least 44 × 44 px, desktop included.
  • Not by colour alone: selection adds a side bar and bold weight; filter chips are filled and show a check; strength, sync and warnings always have an icon and a word; an expiring code shows "Expiring" as text.
  • Secrets stay masked until a deliberate tap. Screen readers announce "Password, hidden" rather than reading out the dots.
